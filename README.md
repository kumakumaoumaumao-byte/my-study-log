# まいにち学習ログ

学習した内容と時間を日付ごとに記録し、これまでの積み重ねを振り返るための小さな学習ログアプリです。

記録はブラウザの `localStorage` に保存されます。サーバーや外部ライブラリは使わず、`index.html` をブラウザで開くだけで利用できます。個人情報は入力しないでください。

## 機能

- 今日の日付を自動セット
- 学習した内容、学習時間、任意のメモを記録
- 日付ごとに1件の記録として保存（同じ日付で保存すると上書き）
- 過去の学習ログの表示、編集、削除
- 学習内容やメモの検索
- 合計・平均の学習時間を表示
- 最近7件の学習時間をグラフで表示

## 使用技術

- HTML
- CSS
- JavaScript
- localStorage

## データの保存

保存キーは `study-log.entries.v1` です。データは現在使用しているブラウザ内に保存され、別の端末やブラウザとは共有されません。

```json
[
  {
    "id": "example-id",
    "date": "2026-04-29",
    "subject": "英単語の復習",
    "minutes": 30,
    "note": "新しい単語を確認した",
    "createdAt": "2026-04-29T10:00:00.000Z",
    "updatedAt": "2026-04-29T10:00:00.000Z"
  }
]
```
